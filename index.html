Feature Puzzles

Single-Image Supervision for Multi-View 3D-Aware Segmentation

Anonymous Authors

Paper arXiv Code BibTeX

Abstract

Humans naturally recognize the same objects consistently across different viewpoints of a 3D scene. However, teaching models such multi-view-consistent perception typically requires videos, calibrated multi-view captures, or reconstructed 3D scenes, which are substantially more expensive and less diverse than large-scale monocular-image data.

We introduce Feature Puzzles, a framework that equips a pretrained multi-view representation with multi-view-consistent segmentation using only single-image annotation. Feature Puzzles decomposes each training image into a puzzle of overlapping crops and treats these crops as synthetic views. Because every crop is tied to the parent image by a known transform, labels and dense teacher features pulled back from the parent agree exactly across crops, which yields cross-view training targets without any multi-view labels. We attach lightweight task heads to the backbone, fuse its multi-layer tokens, and adapt only its late blocks with low-rank adapters. The adapters can be switched off at inference, so the original depth and camera outputs are recovered.

We instantiate the framework for two tasks, both shown below: promptable multi-view segmentation, which propagates prompts from any subset of views to all views in a single forward pass, and open-vocabulary 3D segmentation, which distills DINOv3 features into multi-view-consistent dense features. The multi-view geometric prior comes from the pretrained backbone; Feature Puzzles contributes the semantic supervision. Trained on SA-1B alone, the resulting models remain feed-forward, surpass per-scene optimization on NVOS, and remain competitive with methods trained on in-domain multi-view data.

Feature Puzzles

Single-Image Supervision for Multi-View 3D-Aware Segmentation

Anonymous Authors

Abstract

Humans recognize the same objects across viewpoints of a 3D scene, yet teaching models this multi-view-consistent perception typically requires videos, calibrated multi-view captures, or reconstructed 3D scenes—far more expensive and less diverse than large-scale monocular data. We introduce Feature Puzzles, a framework that adds multi-view-consistent segmentation to a pretrained multi-view representation using only single-image semantic supervision. Each image is decomposed into overlapping crops treated as synthetic views; since every crop is tied to the parent by a known transform, labels and dense teacher features pulled from the parent agree across overlapping crops, yielding cross-view consistent labels. We attach lightweight task heads that fuse the backbone’s multi-layer tokens and adapt only its late blocks with low-rank adapters, which switch off at inference to recover the original depth and camera outputs. The pretrained backbone supplies the multi-view geometric prior; Feature Puzzles supplies only task-specific semantic supervision from single-image labels, with no task-specific multi-view or video annotations. We instantiate the framework for promptable multi-view segmentation—prompts from one or more views predict masks jointly across all views in a single forward pass—and for open-vocabulary 3D segmentation, which distills single-image DINOv3 features into multi-view-consistent dense features. Under this single-image supervision, our feed-forward model attains the best mIoU on NVOS, stays competitive on SPIn-NeRF and ScanNet++ despite in-domain multi-view baselines, and transfers zero-shot to open-vocabulary 3D segmentation.
